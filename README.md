 UPSC-Tracker

A web application designed to help UPSC aspirants organise their preparation and track their study progress.

 Features

- Subject, topic and subtopic management
- Study progress tracking
- Revision management
- Prelims and Mains preparation organisation
- CSAT preparation tracking
- AI-assisted chatbot

 Technologies Used

- Java
- Spring Boot
- Thymeleaf
- HTML and CSS
- MySQL
- Spring Data JPA / Hibernate

 Project Purpose

This project helps UPSC aspirants organise study materials, monitor preparation progress and manage revision in one place.
